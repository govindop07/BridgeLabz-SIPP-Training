# BridgeLabz SIPP Training Repository

Welcome to my repository for the BridgeLabz SIPP Training program! This repository contains all the coursework, projects, and assignments completed during the training.

---

## Branch Overview 🌳

This repository is organized using different branches to keep topics separate and well-structured. The `main` branch serves as the central hub, while other branches are dedicated to specific topics.

Here is a breakdown of the branch structure:

* **`main`**: This is the default branch. It contains this `README.md` file and general information about the repository.

* **`core-java`**: This branch covers fundamental concepts of Core Java.
  
* **`oop`**: This branch focuses on Object-Oriented Programming principles and their implementation in Java. 

* **`dsa`**: This branch contains exercises and projects related to Data Structures and Algorithms. 

* **`collections`**: This branch explores the Java Collections Framework, including Lists, Sets, and Maps.

* **`workshop`**: This branch includes code and materials from various hands-on workshops.
